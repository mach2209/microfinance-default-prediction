# microfinance-default-prediction
Microfinance loan default prediction using theory-guided LLM features — Lumiere Research Scholar Program 2026

Microfinance Loan Default Prediction — Lumiere Research Scholar Program 2026

This repository contains the code and data for a research project testing whether theory-guided LLM features improve microfinance loan default prediction over structured data alone.

Main scripts: comparison_final.py (model comparison), generate_plots_real.py (figures), generate_dataset_summary.py (descriptive statistics)

Dataset: 1,001 Kiva loans (201 defaulted, 800 repaid)
